# מסעות דרום אמריקה — אתר טיולים

אתר סטטי (SvelteKit + adapter-static) שמציג את הטיול לאקוודור, האמזונס ואיי גלאפגוס (22.6–11.7.2027).
בהמשך יורחב לאתר תדמית כללי של החברה.

## עמודים

| כתובת | מה יש שם |
| --- | --- |
| `/` | דף הבית של החברה (כרגע: הטיול הקרוב) |
| `/ecuador-2027/` | המצגת — אנימציות, שלושת העולמות, מפה, כל יום כ"שקופית", סרטון מטיול קודם |
| `/ecuador-2027/day/1/` … `/day/20/` | עמוד לכל יום: תאריך, איפה אנחנו, לו"ז, לינה (ניווט גם בחיצי המקלדת) |
| `/ecuador-2027/included/` | מה כלול ומה לא |
| `/ecuador-2027/itinerary/` | המסלול המלא בעימוד רגיל, להדפסה / PDF, **ללא מחירים** |
| `/ecuador-2027/register/` | מחיר, הרשמה מוקדמת ותשלום דמי רצינות בביט |

## מה לעדכן

כל הפרטים שמשתנים נמצאים בקובץ אחד: **`src/lib/config.ts`**

- `brand` — שם החברה
- `whatsapp`, `email` — פרטי קשר (כפתור וואטסאפ מופיע רק כשיש מספר)
- `pricePerPerson`, `singleSupplement`, `deposit` — המחיר. כל עוד `null` מוצג "המחיר יפורסם בקרוב"
- `bitUrl` — קישור התשלום בביט
- `costSummary` — שורות לטבלת סיכום העלויות בעמוד ההרשמה

תכנית הימים, מה כלול/לא כלול והטקסטים: **`src/lib/data/ecuador.ts`**.
ימים 8–10 (לודג' La Selva) מסומנים `pending: true` — כשמגיעה התכנית מהלודג', ממלאים את `schedule` ומוחקים את `pending`.

## פיתוח

```bash
npm install
npm run dev
npm run build   # הפלט בתיקייה build/
```

לפריסה ב-GitHub Pages תחת תת-תיקייה: `BASE_PATH=/repo-name npm run build`.

## תמונות

- `static/img/trip/` — תמונות מתוך הצעת הספק.
- `static/img/hero/` — תמונות ברזולוציה גבוהה מ-Wikimedia Commons; הקרדיטים והרישיונות ב-`src/lib/data/credits.json` ומוצגים בעמוד `/credits/`.
